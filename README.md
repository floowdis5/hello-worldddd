# Hello Worldddd

A simple "Hello World" program written in Go.

## Description

This is a basic Go program that prints "Hello Worldddd" to the console. It's a great starting point for learning Go.

## Requirements

- Go 1.11 or higher

## Installation

Clone the repository:

```bash
git clone https://github.com/floowdis5/hello-worldddd.git
cd hello-worldddd
```

## Usage

Run the program:

```bash
go run main.go
```

Or build an executable:

```bash
go build
./hello-worldddd
```

## Output

```
Hello Worldddd
```
